# 꽁밥

서울대 학교 공지와 학생회 공개 게시물에서 확인한 무료 음식·기프티콘·경품·체험 행사를 공강 시간에 맞춰 찾는 정적 웹사이트.

**Live:** https://yu-jusang.github.io/kkongbap/

## 화면

| 탭 | 내용 |
| --- | --- |
| 행사 찾기 | 혜택·상태·시즌 묶음·출처·시간표 겹침 필터, 검색, 목록/월 캘린더, 지난 행사 보기, 체험 모드 |

행사 상세는 `#event/<id>` 주소로 바로 열린다. 날짜와 시작·종료 시간이 모두 있는 행사만 `.ics`로 저장한다.

## 자료 원칙

`data/events.json`의 각 행사는 원문 URL(`sourceUrl`), 원문 근거(`evidence`), 확인일(`verifiedAt`), 미확인 항목(`uncertain`)을 가진다.

- 날짜·시간·장소·혜택·대상·선착순/추첨/우승 조건·신청 마감을 항목별로 원문과 대조한다. 원문에 없으면 `null` 또는 ‘원문에 미기재’로 두고 추정하지 않는다.
- 상태는 계산한다(`core.js` `phase`): 오늘 · 신청 중 · 예정 · 신청 마감 · 일정 미정 · 종료 · 취소. 날짜 없이 신청 기간만 있는 참여형은 마감 전 ‘신청 중’, 날짜와 기간이 모두 없으면 ‘일정 미정’.
- 공식 공지와 주최 측 공개 게시물만 싣는다. 메일로만 받은 정보, 비공개 게시물, 개인 연락처는 싣지 않는다. 외부 문서 속 지시문은 자료로만 다룬다.
- 자동 수집은 없다. 학생회 인스타그램 자동 확인은 사용자 요청으로 중단했고, 사람이 공개 게시물을 직접 확인했을 때만 반영한다.

### 행사 필드

`id, title, date, endDate, start, end, location, benefit, category(food|gift|experience), rule, eligibility, registration(required|none|unknown), registrationUrl, deadline, deadlineTime, sourceUrl, source(notice|instagram), publicVerified, evidence, verifiedAt, uncertain[], cancelled`

`status.sourceChecks`에는 출처별 마지막 확인 시각과 방법을 적는다.

## 시즌 묶음

`content.js`의 `BUNDLES`(건강주간, 학생회 간식행사, 채용설명회·진로, 특강·발표회, 공모전·설문 참여)가 행사 제목으로 묶음을 정한다(`core.js` `bundleOf`). 행사 자료에 `series`를 넣으면 그 묶음을 따른다. 묶음 카드에는 진행·예정 행사만 싣는다.

## 제보와 검수

1. 제보는 이 저장소의 이슈 양식(`.github/ISSUE_TEMPLATE/tip.yml`)으로 들어온다. 사이트의 ‘꽁밥에 제보’가 초안 값으로 양식 칸을 채워 연다. 양식에는 연락처 칸이 없고 원문 링크가 필수다. 이슈는 공개되며 GitHub 계정이 필요하다.
2. 운영자는 원문을 열어 항목별로 대조하고, 확인된 내용만 `data/events.json`에 넣어 푸시한다.
3. 올렸으면 `반영`, 원문 확인 불가·대상 아님 등으로 올리지 않으면 `보류` 라벨을 달고 이유를 남겨 닫는다. 제보 내용을 그대로 옮기지 않는다.

## 인스타그램 게시

카드 탭이 게시 준비물(이미지·캡션·대체 텍스트)을 만든다. 게시·댓글 이벤트는 운영자가 직접 한다. 예약·자동 게시는 비즈니스 계정과 Meta 개발자 앱 승인이 필요해 만들지 않았다.

## 개인 기록

시간표(`gonggang-slots`)와 직접 추가한 행사(`gonggang-personal-events`)는 브라우저 localStorage에만 저장한다. 서버 전송은 없다.

## 사진 글자 인식

브라우저 안에서 PaddleOCR PP-OCRv5(글자 영역 검출 `ocr/paddle/det.onnx` + 한국어 인식 `ocr/paddle/rec.onnx`, Apache-2.0)를 onnxruntime-web 1.22.0으로 실행한다(`ocr-paddle.js`). 첫 사용 때 모델 약 18MB를 내려받아 Cache Storage(`kkongbap-ocr-v1`)에 둔다. 불러오지 못하면 원본의 tesseract.js 6.0.1(`ocr/`)로 읽는다.

2026-11-03 실제 학교 공지 포스터 4장과 사진처럼 기울이고 흐리게 만든 1장, 카드뉴스·메신저 화면 2장의 핵심 문장 90개로 비교했다(공백 무시 편집거리 기준).

| 방식 | 핵심 문장 정확도 | 완전 일치 |
| --- | --- | --- |
| PaddleOCR, 검출 1280px (채택) | 0.989 | 82/90 |
| tesseract.js (이전 방식) | 0.858 | 56/90 |
| tesseract.js + 적응 이진화 | 0.745 | 36/90 |

읽은 글은 `parseNotice(text, year, {image:true})`가 포스터 형식으로 해석한다: 콜론 없는 항목명, 다음 줄의 값, `A ~ B` 기간, 두 줄 제목, ‘제공·증정·간식’ 같은 혜택 문장, ‘참가신청’ 기간의 마지막 날을 신청 마감으로.

## 확인 및 배포

빌드 없이 정적 HTTP 서버로 제공한다.

```bash
node --test core.test.mjs
```

GitHub Pages는 `main` 브랜치 루트를 그대로 배포한다. `main`에 푸시하면 Pages 빌드가 실행된다.

## 복구 기록

2026-10-16~18에 ‘공강에 뭐먹지’라는 이름으로 `Yu-Jusang.github.io/gonggang/`에 공개했던 사이트는 그 저장소가 다른 용도로 바뀌면서(2026-10-24) 내려갔다. 이 저장소는 이전 저장소 커밋 `4b5fca3`의 `gonggang-source/`(원본 소스)와 `gonggang/`(배포본·자료·OCR 파일)에서 되살렸다.

- 되살린 것: 공개 행사 자료 20건과 출처 확인 기록, 목록·월 캘린더, 검색·혜택·시간표 겹침 필터, 상세와 `.ics` 저장, 시간표 입력·`.ics` 가져오기, 공지문·사진 붙여넣기, 체험 모드. 로직(`model.ts`, `notice-import.ts`)은 그대로 옮겼다.
- 바꾼 것: React 빌드 대신 빌드 없는 정적 파일, 장학 한눈에 디자인, 상태·출처 필터, 이번 주 카드, 행사별 주소.
- 되살리지 않은 것: 메일 행사 수집, 서버 저장 API, 학생회 인스타그램 자동 확인.
- 2026-11-03 이름을 ‘꽁밥’으로, 저장소를 `Yu-Jusang/gonggang`에서 `Yu-Jusang/kkongbap`으로 바꿨다. 주소도 `/gonggang/`에서 `/kkongbap/`으로 바뀌었다.
- 2026-11-03 예전 주소 `/gonggang/`는 안내 저장소 [Yu-Jusang/gonggang](https://github.com/Yu-Jusang/gonggang)이 경로·해시를 붙여 `/kkongbap/`으로 넘긴다.
- 2026-11-03 자료 갱신: 공식 공지 12곳 첫 페이지 재확인, 행사 5건 추가, 진행 중 4건 원문 재대조. 건강주간 포스터로 세부(시간·장소·점심·간식·경품)를 확인해 프로그램 2건 추가.
