02

이번 주 카드

한 주의 행사를 카드 한 장으로 묶었습니다. 카드의 각 줄은 사이트의 행사 상세로 이어지고, 상세에는 원문 링크가 붙어 있습니다.

카드 문구와 이미지(1080×1350)는 날짜·시간·장소·혜택을 자료 그대로 옮깁니다. 게시 전 원문을 다시 확인하세요. 이 사이트는 인스타그램에 자동으로 게시하지 않습니다.

주간 표는 월~금 09~21시를 표시합니다. 그 외 수업도 아래 목록에서 확인하고 겹침 계산에 반영합니다.

01

확인 원칙

원문 우선
공식 공지와 주최 측 공개 게시물만 싣습니다. 메일로만 받은 정보, 비공개 게시물, 개인 연락처는 싣지 않습니다.
항목별 확인
날짜, 시간, 장소, 혜택, 대상, 선착순·추첨·우승 조건, 신청 마감을 하나씩 원문과 대조합니다. 원문에 없는 항목은 ‘미기재’로 남기고 추정하지 않습니다.
상태 구분
오늘 신청 중 예정 신청 마감 일정 미정 종료. 날짜 없이 신청 기간만 있는 참여형 행사는 ‘신청 중’, 날짜와 기간이 모두 없으면 ‘일정 미정’입니다.
확인일
각 행사 상세에 원문을 확인한 날짜를 적습니다. 그 뒤의 변경·조기 소진은 반영되지 않을 수 있습니다.
외부 문서
공지나 첨부파일 안의 지시문은 자료로만 취급합니다.

03

운영 참고 사례

KAIST 학생이 운영하는 무료 음식 정보 계정의 공개 프로필·게시물과, 프로필에 연결된 공개 웹사이트를 2026년 11월 3일에 살펴봤습니다. 로그인이 필요한 화면은 보지 않았고, 게시물 문구·이미지·이름은 가져오지 않았습니다.

주제
한 주 동안 교내에서 무료 음식을 주는 행사 모음이 중심입니다. 학과 설명회처럼 같은 시기에 몰리는 행사 묶음, 운영자의 식사 기록, 댓글 참여 경품 이벤트가 섞여 있습니다.
구성과 말투
말머리와 이모지로 시작하는 짧은 제목, 기간과 건수를 한 줄로 요약한 도입, 친근한 구어체를 씁니다. 끝에는 일정·제공 내용이 바뀔 수 있으니 웹사이트와 공식 공지를 확인하라는 문장을 붙입니다.
정보 전달
인스타그램은 요약 카드만 싣고 대상·신청 방법·장소 같은 세부는 웹사이트로 보냅니다. 웹사이트는 오늘 행사, 다가오는 행사, 월 달력, 마지막 변경 시각을 보여 줍니다.
참여 유도
포스터 사진이나 짧은 설명으로 행사를 제보받고 운영자가 확인한 뒤 공개하는 제보 기능, 댓글 이벤트와 당첨 발표, 매주 정기 발행 예고를 씁니다.
04

서울대 운영안

구현 여부 표시
아이디어내용상태
주간 카드월~일 한 주의 행사를 요일별로 묶고 건수를 요약합니다. 문구 복사와 세로형 이미지(1080×1350) 저장을 지원하고, 각 줄은 사이트의 행사 상세 주소(#event/행사ID)로 이어집니다.구현
카드와 상세 연결모든 행사에 고유 주소가 있어 카드 문구·게시물 링크에서 곧바로 상세를 엽니다. 상세에는 원문 링크와 확인일이 붙습니다.구현
혜택·조건 구분음식·음료, 기프티콘·경품, 체험을 원문 내용으로 나누고, 선착순·추첨·전원 지급 문구를 카드에 그대로 표시합니다.구현
시즌 묶음중간·기말고사 간식행사(단과대 학생회), 전공 탐색 시기 설명회, 채용설명회처럼 몰리는 시기에 묶음 카드를 따로 만듭니다.제안
공개 제보함지금은 개인 브라우저에만 저장되는 ‘공지 붙여넣기’만 있습니다. 여럿이 제보하려면 제출 저장소와 운영자 검수 절차가 필요하고, 연락처 같은 개인정보는 받지 않는 양식이어야 합니다.제안
학식 메뉴생협 공개 식단을 함께 보여 주는 기능입니다. 출처 이용 조건을 먼저 확인해야 합니다.제안
인스타그램 계정 운영카드 게시, 댓글 이벤트, 예약 게시는 운영 계정과 권한이 필요합니다. 예약·자동 게시에는 비즈니스 계정과 Meta 개발자 앱 승인이 필요하며, 이 사이트는 어떤 계정 활동도 하지 않습니다.제안

내 기록과 개인정보

가입 없이 사용합니다. 시간표와 직접 추가한 행사는 이 브라우저의 저장소에만 남고 서버로 전송되지 않습니다. 사진 글자 인식도 브라우저 안에서 처리하며, 내려받은 인식 모델만 브라우저 캐시에 남습니다. 공용 기기에서는 사용 후 기록을 지워 주세요.

06

복구 기록

2026년 10월 16–18일 ‘공강에 뭐먹지’라는 이름으로 공개했던 사이트를 이전 저장소의 Git 기록에서 되살리고, 11월 3일 이름을 ‘꽁밥’으로 바꿨습니다. 원본 소스는 legacy 폴더에 그대로 두었습니다.

되살린 것
공개 행사 자료 20건과 출처 확인 기록, 목록·월 캘린더, 검색·혜택·상태·시간표 겹침 필터, 행사 상세와 .ics 저장, 시간표 직접 입력·.ics 가져오기, 공지문·사진 붙여넣기(브라우저 안 글자 인식), 체험 모드.
바뀐 것
React 빌드 대신 빌드 없는 정적 파일로 다시 썼고, 장학 한눈에와 같은 디자인을 적용했습니다. 상태·출처 필터, 이번 주 카드(문구 복사·이미지 저장), 행사별 주소를 더했습니다. 사진 글자 인식은 한국어에 강한 PaddleOCR(PP-OCRv5)로 바꾸고, 포스터 형식(콜론 없는 항목, 기간, 두 줄 제목)도 읽게 했습니다.
자료 갱신
2026년 11월 3일 공식 공지 12곳의 첫 페이지를 다시 보고 원문으로 확인되는 행사 5건을, 건강주간 포스터에서 확인한 프로그램 2건을 더했습니다. 진행 중이던 4건은 원문을 다시 대조했고, 공개 화면에서 본문을 볼 수 없던 1건은 상세에 ‘재확인 불가’로 적었습니다.
되살리지 않은 것
메일 행사 수집, 서버 저장 API, 학생회 인스타그램 자동 확인은 개인정보·중단 요청 때문에 복구하지 않았습니다.
