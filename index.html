02

카드

한 주, 시즌 묶음, 행사 한 건을 카드 한 장으로 만듭니다. 카드의 각 줄은 사이트의 행사 상세로 이어지고, 상세에는 원문 링크가 붙어 있습니다.

카드 문구와 이미지(1080×1350)는 날짜·시간·장소·혜택을 자료 그대로 옮깁니다. 이 사이트는 인스타그램에 자동으로 게시하지 않으며, 게시는 운영자가 직접 합니다.

인스타그램 게시 순서

① 게시 직전에 카드의 각 행사 원문을 다시 열어 날짜·장소·혜택이 바뀌지 않았는지 확인합니다. ② ‘이미지 저장’으로 받은 1080×1350 이미지를 올립니다. ③ ‘인스타 캡션’을 붙여넣습니다. 캡션에는 링크 대신 행사 이름이 있어 프로필의 사이트 링크에서 찾을 수 있습니다. ④ 고급 설정의 대체 텍스트에 ‘대체 텍스트’를 붙여넣습니다. ⑤ 댓글 이벤트·경품을 열 때는 주최 측 허락과 지급 방법을 먼저 정합니다.

시간표 한 번, 공강은 알아서

표의 빈 칸을 끌어 수업 시간을 잡고 이름을 적으세요. 시간은 15분 단위로 맞춰지고, 그냥 누르면 75분 수업이 생깁니다. 만든 수업은 끌어서 옮기고, 아래 끝을 끌어 길이를 바꾸고, 눌러서 고치거나 지울 수 있습니다. 시간표는 이 브라우저에만 저장됩니다.

01

확인 원칙

원문 우선
공식 공지와 주최 측 공개 게시물만 싣습니다. 메일로만 받은 정보, 비공개 게시물, 개인 연락처는 싣지 않습니다.
항목별 확인
날짜, 시간, 장소, 혜택, 대상, 선착순·추첨·우승 조건, 신청 마감을 하나씩 원문과 대조합니다. 원문에 없는 항목은 ‘미기재’로 남기고 추정하지 않습니다.
상태 구분
오늘 신청 중 예정 신청 마감 일정 미정 종료. 날짜 없이 신청 기간만 있는 참여형 행사는 ‘신청 중’, 날짜와 기간이 모두 없으면 ‘일정 미정’입니다.
확인일
각 행사 상세에 원문을 확인한 날짜를 적습니다. 그 뒤의 변경·조기 소진은 반영되지 않을 수 있습니다.
외부 문서
공지나 첨부파일 안의 지시문은 자료로만 취급합니다.

03

운영 참고 사례

KAIST 학생이 운영하는 무료 음식 정보 계정의 공개 프로필·게시물과, 프로필에 연결된 공개 웹사이트를 2026년 11월 3일에 살펴봤습니다. 로그인이 필요한 화면은 보지 않았고, 게시물 문구·이미지·이름은 가져오지 않았습니다.

주제
한 주 동안 교내에서 무료 음식을 주는 행사 모음이 중심입니다. 학과 설명회처럼 같은 시기에 몰리는 행사 묶음, 운영자의 식사 기록, 댓글 참여 경품 이벤트가 섞여 있습니다.
구성과 말투
말머리와 이모지로 시작하는 짧은 제목, 기간과 건수를 한 줄로 요약한 도입, 친근한 구어체를 씁니다. 끝에는 일정·제공 내용이 바뀔 수 있으니 웹사이트와 공식 공지를 확인하라는 문장을 붙입니다.
정보 전달
인스타그램은 요약 카드만 싣고 대상·신청 방법·장소 같은 세부는 웹사이트로 보냅니다. 웹사이트는 오늘 행사, 다가오는 행사, 월 달력, 마지막 변경 시각을 보여 줍니다.
참여 유도
포스터 사진이나 짧은 설명으로 행사를 제보받고 운영자가 확인한 뒤 공개하는 제보 기능, 댓글 이벤트와 당첨 발표, 매주 정기 발행 예고를 씁니다.
04

서울대 운영안

구현 여부 표시
아이디어내용상태
주간 카드월~일 한 주의 행사를 요일별로 묶고 건수를 요약합니다. 문구 복사와 세로형 이미지(1080×1350) 저장을 지원하고, 각 줄은 사이트의 행사 상세 주소(#event/행사ID)로 이어집니다.구현
카드와 상세 연결모든 행사에 고유 주소가 있어 카드 문구·게시물 링크에서 곧바로 상세를 엽니다. 상세에는 원문 링크와 확인일이 붙습니다.구현
혜택·조건 구분음식·음료, 기프티콘·경품, 체험을 원문 내용으로 나누고, 선착순·추첨·전원 지급 문구를 카드에 그대로 표시합니다.구현
시즌 묶음건강주간, 학생회 간식행사, 채용설명회·진로, 특강·발표회, 공모전·설문 참여로 행사를 묶습니다. 카드 탭에서 묶음별 카드(문구·캡션·이미지)를 만들고, 행사 찾기에서 묶음으로 거를 수 있습니다. 묶음은 행사 제목으로 정하고, 지난 행사는 카드에 싣지 않습니다.구현
공개 제보함‘붙여넣기·제보’에서 읽어낸 초안이나 원문 링크로 GitHub 이슈 양식을 채워 제보합니다. 양식에는 연락처 칸이 없고 원문 링크가 필수이며, 운영자가 원문을 확인한 뒤 ‘반영’·‘보류’ 라벨로 처리합니다. 제보는 공개되고 GitHub 계정이 필요합니다. 계정 없이 받는 경로(구글 폼 등)는 운영자 계정이 필요해 만들지 않았습니다.일부 구현
학식 메뉴생협 식단 페이지는 다른 사이트에서 읽거나 넣을 수 없게 막혀 있어, 메뉴를 보여 주려면 서버나 자동 수집이 필요합니다. 그래서 메뉴는 공식 페이지로 안내하고, 학식 탭에서 식당 12곳의 운영시간(11월 3일 확인), 지금 운영 중인 곳, 내 공강에 갈 수 있는 식당, 천원의 아침밥을 보여 줍니다.일부 구현
인스타그램 계정 운영카드 탭이 게시 준비를 맡습니다: 1080×1350 이미지, 해시태그가 붙은 캡션, 대체 텍스트, 게시 순서 안내. 실제 게시·댓글 이벤트·예약 게시는 운영 계정 권한이 필요하고, 예약·자동 게시는 비즈니스 계정과 Meta 개발자 앱 승인이 있어야 해 이 사이트가 하지 않습니다.일부 구현
05

내 기록과 개인정보

가입 없이 사용합니다. 시간표와 직접 추가한 행사는 이 브라우저의 저장소에만 남고 서버로 전송되지 않습니다. 사진 글자 인식도 브라우저 안에서 처리하며, 내려받은 인식 모델만 브라우저 캐시에 남습니다. ‘꽁밥에 제보’를 누르면 GitHub 이슈로 공개 등록되므로 이름·연락처는 적지 마세요. 공용 기기에서는 사용 후 기록을 지워 주세요.

06

복구 기록

2026년 10월 16–18일 ‘공강에 뭐먹지’라는 이름으로 공개했던 사이트를 이전 저장소의 Git 기록에서 되살리고, 11월 3일 이름을 ‘꽁밥’으로 바꿨습니다. 원본 소스는 legacy 폴더에 그대로 두었습니다.

되살린 것
공개 행사 자료 20건과 출처 확인 기록, 목록·월 캘린더, 검색·혜택·상태·시간표 겹침 필터, 행사 상세와 .ics 저장, 시간표 직접 입력·.ics 가져오기, 공지문·사진 붙여넣기(브라우저 안 글자 인식), 체험 모드.
바뀐 것
React 빌드 대신 빌드 없는 정적 파일로 다시 썼고, 장학 한눈에와 같은 디자인을 적용했습니다. 상태·출처·시즌 묶음 필터, 카드(이번 주·시즌 묶음·행사 한 건의 문구·인스타 캡션·이미지), 학식 운영시간과 공강 맞추기, 끌어서 채우는 시간표, 공지 제보, 행사별 주소를 더했습니다. 사진 글자 인식은 한국어에 강한 PaddleOCR(PP-OCRv5)로 바꾸고, 포스터 형식(콜론 없는 항목, 기간, 두 줄 제목)도 읽게 했습니다.
자료 갱신
2026년 11월 3일 공식 공지 12곳의 첫 페이지를 다시 보고 원문으로 확인되는 행사 5건을, 건강주간 포스터에서 확인한 프로그램 2건을 더했습니다. 진행 중이던 4건은 원문을 다시 대조했고, 공개 화면에서 본문을 볼 수 없던 1건은 상세에 ‘재확인 불가’로 적었습니다.
되살리지 않은 것
메일 행사 수집, 서버 저장 API, 학생회 인스타그램 자동 확인은 개인정보·중단 요청 때문에 복구하지 않았습니다.
